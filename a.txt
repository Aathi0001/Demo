## WorkLog Page

Add

```ts
showTimeline = false;
```

Methods

```ts
openTimeline(): void {

    this.showTimeline = true;

}

closeTimeline(): void {

    this.showTimeline = false;

}
```

---

When a week is clicked

```ts
jumpToWeek(
    weekOffset:number
):void{

    this.request.week_offset =
        weekOffset;

    this.closeTimeline();

    this.loadWorkLogs();

}
```
