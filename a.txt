Expected Backend Response

Instead of returning a flat list, I recommend returning:

[
    {
        "day": "Monday",
        "logs": [
            {
                "worklog_id":1,
                "title":"Login API",
                "notes":"Completed login module",
                "project_name":"Personal Hub",
                "category_name":"Backend",
                "duration":"02:30"
            },
            {
                "worklog_id":2,
                "title":"JWT",
                "notes":"Implemented JWT",
                "project_name":"Personal Hub",
                "category_name":"Backend",
                "duration":"01:20"
            }
        ]
    },
    {
        "day":"Tuesday",
        "logs":[]
    },
    {
        "day":"Wednesday",
        "logs":[]
    }
]




Small improvement I'd recommend

Instead of storing duration as "2:5" or "10:3", format it before sending:

duration:
`${String(value.hours).padStart(2,'0')}:${String(value.minutes).padStart(2,'0')}`

That way the backend always receives:

00:30
01:05
02:45
10:00

which is cleaner and easier to display later.
